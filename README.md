# Analyst Data
analisis data total kasus COVID-19 berdasarkan negara dengan jumlah kasus tertinggi. Data menunjukkan bahwa Amerika Serikat memiliki jumlah kasus tertinggi, diikuti oleh India, Prancis, dan Brasil. Selisih jumlah kasus antar negara cukup signifikan, dengan Amerika Serikat mencatat angka yang jauh lebih tinggi dibandingkan negara lainnya. Pola ini mencerminkan tingkat penyebaran dan penanganan pandemi yang berbeda-beda di setiap negara.
analis data ini mencakup total kasus, kematian, dan yang berhasil disembuhkan
